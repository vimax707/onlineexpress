# onlineexpress

Platform jasa digital. Folder `kantor-ai/` berisi "Kantor AI" (nama tampil: Sriwijaya Andalan Perkasa),
yaitu tampilan kantor 3D dari aktivitas Claude Code. Baca `kantor-ai/RANGKUMAN.md` sebelum mengubahnya.

Aturan yang diminta pemilik untuk Kantor AI:
- Semua yang tampil harus kerja sungguhan. Jangan buat status acak atau aktivitas karangan.
- Hook hanya mencatat nama alat dan nama file. Jangan catat isi file, isi perintah, atau isi prompt.
  Hook tidak boleh memperlambat atau menggagalkan kerja Claude (selalu exit 0).
- Server hanya untuk komputer ini (127.0.0.1) dan memakai Node murni tanpa library tambahan.
- Jangan ubah atau hapus file kerja pemilik. Cadangkan pengaturan Claude Code sebelum mengubahnya.
- Tampilan bersih dan terang, nama karyawan kecil.
- Setelah mengubah sesuatu, perbarui `kantor-ai/RANGKUMAN.md` dan sebutkan apa yang sudah dan belum diuji.
